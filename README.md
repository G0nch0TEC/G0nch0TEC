## 👻 Sobre mí

Estudiante de **Ingeniería de Software** enfocado en construir proyectos reales y aprender de forma continua. Me gusta entender el *porqué* de cada decisión técnica: desde la arquitectura del backend hasta cómo se guarda un token en el dispositivo.

- 🔭 Actualmente desarrollo **CFT Reborn**: una API en Spring Boot y una app Flutter para Android y Windows.
- 🌱 Aprendiendo **Dart y Flutter**, traduciendo mis patrones de Java a un nuevo lenguaje.
- 🔐 Profundizando en **autenticación con JWT**, Spring Security y buenas prácticas de seguridad.
- 🧱 Organizo mis backends por capas: controller, casos de uso, DTOs y repositorios.
- 🎯 Busco **prácticas profesionales / primer empleo** en desarrollo de software.
